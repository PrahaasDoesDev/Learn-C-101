# Conditional Flow Statements in C

Conditional statements choose which statements execute based on an expression.

## `if` and `else`

```c
if (condition) {
    /* runs when condition is nonzero */
} else {
    /* runs when condition is zero */
}
```

Example:

```c
int number = 7;
if (number % 2 == 0) {
    puts("Even");
} else {
    puts("Odd");
}
```

## `else if`

An `else if` chain checks conditions in order and runs the first matching branch:

```c
int score = 82;
if (score >= 90) {
    puts("A");
} else if (score >= 75) {
    puts("B");
} else if (score >= 60) {
    puts("C");
} else {
    puts("Needs improvement");
}
```

Order matters. Test stricter ranges first so an earlier broad condition does not hide a later one.

## `switch`

`switch` selects among constant integer or character cases. Each case normally ends with `break` to avoid continuing into the next case.

```c
char operation = '+';
int a = 4;
int b = 3;

switch (operation) {
    case '+':
        printf("%d\n", a + b);
        break;
    case '-':
        printf("%d\n", a - b);
        break;
    default:
        puts("Unsupported operation");
        break;
}
```

The controlling expression must have an integer type. `switch` does not directly match strings or floating-point values. Multiple `case` labels can share a block. Falling through without a `break` is possible but should be intentional and clearly documented.

## Conditional operator `?:`

The conditional operator selects one of two expressions and produces a value:

```c
int a = 10;
int b = 20;
int maximum = (a > b) ? a : b;
```

Use it for short, simple choices. Use `if`/`else` for multi-step actions or complicated logic.

## Choosing a construct

| Use | When |
|---|---|
| `if` / `else` | conditions, ranges, or multiple variables |
| `switch` | one integer or character matched against fixed values |
| `?:` | a short expression that chooses a value |

Practice by checking whether a number is positive, negative, or zero; finding the largest of three values; and building a small menu with `switch`.
