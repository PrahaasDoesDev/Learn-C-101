# Flow Control: Conditional Programming in C

By default, C statements execute from top to bottom. Control-flow statements let a program choose between paths or repeat work.

| Flow | Purpose | C constructs |
|---|---|---|
| Sequential | execute in order | ordinary statements |
| Conditional | choose which statements run | `if`, `else`, `switch`, `?:` |
| Repetition | repeat statements | `while`, `do-while`, `for` |

## Conditions

C treats an integer expression with value zero as false and a nonzero value as true. Comparison and logical operators produce `0` or `1`.

```c
#include <stdio.h>

int main(void)
{
    int is_raining = 1;

    if (is_raining) {
        puts("Take an umbrella.");
    } else {
        puts("No umbrella needed.");
    }

    return 0;
}
```

Use braces for blocks, even when a branch contains only one statement. They make the structure clear and help prevent accidental changes in behavior.
