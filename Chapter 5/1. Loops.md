# Loops

Loops repeat a block of statements. Choose a loop based on when its condition should be checked and whether the number of repetitions is known.

## `while`

`while` checks its condition before each iteration. Its body may run zero times.

```c
int count = 1;
while (count <= 5) {
    printf("%d\n", count);
    ++count;
}
```

Make sure something in the loop eventually makes the condition false, or the loop may never end.

## `do-while`

`do-while` checks the condition after the body, so the body always runs at least once. Note the semicolon after the condition.

```c
int choice;
do {
    puts("Enter 0 to exit:");
    if (scanf("%d", &choice) != 1) {
        break;
    }
} while (choice != 0);
```

## `for`

Use `for` when initialization, continuation condition, and update belong together:

```c
for (int i = 0; i < 5; ++i) {
    printf("%d ", i);
}
putchar('\n');
```

The declaration of `i` in the initialization clause requires C99 or later. In C90, declare it before the loop.

## `break` and `continue`

- `break` exits the nearest loop or `switch`.
- `continue` skips the rest of the current loop body and proceeds to the next iteration.

```c
for (int i = 0; i < 10; ++i) {
    if (i == 3) {
        continue;
    }
    if (i == 7) {
        break;
    }
    printf("%d ", i);  // 0 1 2 4 5 6
}
```

## Nested loops and common mistakes

Loops can be nested, but each loop should use a clear control variable. Common problems include an off-by-one condition (`i <= length` when valid indices end at `length - 1`), forgetting the update, and changing the wrong variable. Check loop boundaries carefully, especially when working with arrays.

## Choosing a loop

| Loop | Best fit |
|---|---|
| `while` | repeat while a condition remains true |
| `do-while` | body must run at least once |
| `for` | counted repetition or a clear initialization/condition/update |
