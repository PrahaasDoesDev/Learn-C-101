# Compound Assignment Operators

A compound assignment applies an operation and stores its result back into the left operand.

```c
int value = 10;
value = value + 5;
value += 5;              // equivalent here to value = value + 5
```

## Operators

| Operator | Meaning |
|---|---|
| `+=` `-=` `*=` `/=` `%=` | arithmetic and remainder |
| `&=` `|=` `^=` | bitwise AND, OR, XOR |
| `<<=` `>>=` | shift left or right |

The remainder and bitwise operators require integer operands. Compound assignment is not available for logical `&&` or `||`, and C has no exponentiation operator; use `pow` from `<math.h>` for floating-point powers.

```c
#include <stdio.h>

int main(void)
{
    int value = 45;
    value += 5;  // 50
    value -= 5;  // 45
    value *= 2;  // 90
    value /= 3;  // 30
    value %= 11; // 8
    printf("%d\n", value);
    return 0;
}
```

`/=` follows the type's division rules: if the left operand is an integer, a fractional result is discarded. Avoid shifting by a negative count or by a count greater than or equal to the width of the promoted left operand; such shifts have undefined behavior.
