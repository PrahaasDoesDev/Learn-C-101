# Integral Promotions

In many expressions, integer types narrower than `int` are first promoted to `int` (or to `unsigned int` if `int` cannot represent every value). This is called **integer promotion**.

```c
#include <stdio.h>

int main(void)
{
    signed char a = 100;
    signed char b = 100;
    int sum = a + b;           // operands promote to int; sum is 200
    printf("%d\n", sum);
    return 0;
}
```

The arithmetic result can be wider than the original operands. Assigning it back to a narrow type may change the value or, for an unrepresentable signed result, may be implementation-defined or otherwise depend on the conversion rules. Do not rely on wraparound for signed values.

Integer promotions also apply to many operations involving `char`, `short`, and enumerated types. The usual arithmetic conversions then determine a common type when operands differ.

Use `int` for ordinary arithmetic, and explicitly validate values before converting to narrower types. For format strings, remember that `char` and `short` arguments passed through `...` are promoted, so `%d` is commonly used to print them after promotion.
