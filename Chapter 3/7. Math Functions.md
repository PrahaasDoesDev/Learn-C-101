# Math Functions in C

The standard mathematical functions are declared in `<math.h>`.

| Function | Purpose |
|---|---|
| `floor`, `ceil`, `round`, `trunc` | rounding |
| `fabs` | floating-point absolute value |
| `pow`, `sqrt` | powers and roots |
| `exp`, `log`, `log10` | exponential and logarithms |
| `sin`, `cos`, `tan` | trigonometry |

Most of these functions take and return `double`. Many have `f` and `l` variants for `float` and `long double`, such as `sqrtf` and `sqrtl`.

```c
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("%.1f\n", floor(3.7));  // 3.0
    printf("%.1f\n", ceil(3.2));   // 4.0
    printf("%.1f\n", round(3.5));  // 4.0
    printf("%.1f\n", fabs(-7.5));  // 7.5
    printf("%.1f\n", sqrt(16.0));  // 4.0
    printf("%.1f\n", pow(2.0, 3.0)); // 8.0
    return 0;
}
```

`floor` rounds toward negative infinity, `ceil` toward positive infinity, `trunc` toward zero, and `round` to the nearest integer with halfway cases away from zero. These functions return floating-point values.

`log` is the natural logarithm; use `log10` or `log2` for other bases. Trigonometric functions use radians. Results are approximate; do not compare computed floating-point values with `==`.

On some Unix-like systems, link the math library with `-lm`:

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic main.c -lm -o main
```
