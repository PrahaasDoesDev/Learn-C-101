# Basic Data Operations

C's arithmetic operators let you calculate with integer and floating-point values.

| Operator | Meaning | Example |
|---|---|---|
| `+` | addition | `7 + 3` is `10` |
| `-` | subtraction | `7 - 3` is `4` |
| `*` | multiplication | `7 * 3` is `21` |
| `/` | division | `7 / 3` is `2` for integers |
| `%` | remainder | `7 % 3` is `1` |

```c
#include <stdio.h>

int main(void)
{
    int a = 7;
    int b = 3;

    printf("%d\n", a + b);  // 10
    printf("%d\n", a - b);  // 4
    printf("%d\n", a * b);  // 21
    printf("%d\n", a / b);  // 2
    printf("%d\n", a % b);  // 1
    printf("%.2f\n", 7.0 / 3); // 2.33
    return 0;
}
```

## Division and remainder

When both operands of `/` are integers, the fractional part is discarded toward zero. At least one floating-point operand gives a floating-point calculation. Integer division by zero is undefined behavior; check the divisor before dividing.

`%` is defined for integer operands only. It is often used to test parity (`n % 2 == 0`) or obtain a remainder. The result's sign follows the dividend in modern C.

## Order of operations

Parentheses have the highest priority. Multiplication, division, and remainder bind more tightly than addition and subtraction; operators at the same level generally group left to right.

```c
int a = 2 + 3 * 4;       // 14
int b = (2 + 3) * 4;     // 20
int c = 20 / 4 * 2;      // 10: (20 / 4) * 2
```

When an expression is not immediately clear, add parentheses.
