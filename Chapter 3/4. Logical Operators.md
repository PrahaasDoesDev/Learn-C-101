# Logical Operators

Logical operators combine conditions or reverse a condition. In a condition, zero is false and any nonzero value is true.

| Operator | Meaning | Result |
|---|---|---|
| `&&` | logical AND | true when both operands are true |
| `||` | logical OR | true when either operand is true |
| `!` | logical NOT | reverses truth |

```c
#include <stdio.h>

int main(void)
{
    int age = 20;
    int has_id = 1;

    if (age >= 18 && has_id) {
        puts("Entry allowed");
    }

    if (age < 18 || !has_id) {
        puts("Entry denied");
    }
    return 0;
}
```

## Short-circuit evaluation

`&&` and `||` evaluate left to right and may skip their right operand:

```c
if (divisor != 0 && value / divisor > 2) {
    /* division is evaluated only when divisor is not zero */
}
```

This makes the order of conditions important. The left side of `&&` must establish any safety requirement for the right side.

## Precedence

`!` binds more tightly than `&&`, which binds more tightly than `||`. Use parentheses when mixing conditions:

```c
if ((age >= 18 && has_id) || is_guest) {
    /* ... */
}
```

C logical operators produce `int` values `0` or `1`. For Boolean variables in C99-C17, include `<stdbool.h>` and use `bool`, `true`, and `false`.
