# Output Formatting

C commonly formats terminal output with `printf` from `<stdio.h>`. A format string contains ordinary text and conversion specifiers describing how each additional argument should be printed.

```c
#include <stdio.h>

int main(void)
{
    int count = 3;
    double price = 2.5;

    printf("Count: %d, price: %.2f\n", count, price);
    return 0;
}
```

## Common `printf` conversions

| Specifier | Argument type | Example |
|---|---|---|
| `%d` or `%i` | `int` | `printf("%d", count)` |
| `%u` | `unsigned int` | `printf("%u", amount)` |
| `%ld`, `%lld` | `long`, `long long` | match the argument type |
| `%f` | `double` | `printf("%.2f", price)` |
| `%e`, `%g` | `double` | scientific or compact notation |
| `%c` | `int` value of a character | `printf("%c", letter)` |
| `%s` | pointer to a null-terminated character array | `printf("%s", text)` |
| `%zu` | `size_t` | `printf("%zu", sizeof value)` |
| `%%` | no argument | print a percent sign |

The type and number of arguments must match the format string. A mismatch can cause undefined behavior. In particular, `%f` prints a `double` in `printf`; a `float` is promoted to `double` in a variadic call.

## Width, alignment, and precision

```c
printf("|%10d|\n", 42);       // right-aligned, minimum width 10
printf("|%-10d|\n", 42);      // left-aligned
printf("%08d\n", 42);         // zero padded
printf("%.2f\n", 3.14159);    // two digits after decimal point
printf("%10.2f\n", 3.14159);  // width 10 and two decimal places
```

Width is a minimum, not a maximum. Precision means digits after the decimal for `%f`, but has different meanings for other conversions. Avoid arbitrary width/precision values derived from untrusted input.

## Newlines and flushing

Use `\n` to add a newline. Output is buffered, so `fflush(stdout)` can force pending output to be sent immediately when needed, such as for an interactive prompt:

```c
printf("Enter a number: ");
fflush(stdout);
```

## Formatted input

`scanf` uses its own format string. Pass pointers for destinations and check how many conversions succeeded:

```c
int number;
if (scanf("%d", &number) == 1) {
    printf("You entered %d\n", number);
}
```

For general line input, `fgets` is often easier to bound safely. The `printf` and `scanf` format rules are not identical; always consult the correct format for each function.
