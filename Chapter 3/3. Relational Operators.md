# Relational Operators

Relational and equality operators compare values. In C, each comparison evaluates to an `int` value: `1` for true or `0` for false.

| Operator | Meaning |
|---|---|
| `==` | equal |
| `!=` | not equal |
| `>` | greater than |
| `<` | less than |
| `>=` | greater than or equal |
| `<=` | less than or equal |

```c
#include <stdio.h>

int main(void)
{
    int first = 10;
    int second = 5;

    printf("%d\n", first == second); // 0
    printf("%d\n", first != second); // 1
    printf("%d\n", first > second);  // 1
    printf("%d\n", first < second);  // 0
    return 0;
}
```

## `=` versus `==`

`=` assigns a value; `==` compares two values:

```c
int age = 20;
if (age == 20) {
    puts("Age is 20");
}
```

Accidentally writing `if (age = 20)` assigns 20 and tests the resulting nonzero value. Enable warnings and write comparisons carefully.

## Comparing floating-point values

Computed floating-point values can be rounded, so exact equality may not behave as intended. Compare their difference against a suitable tolerance instead.

Do not chain comparisons as in `a < b < c`; C evaluates that as `(a < b) < c`. Write `(a < b) && (b < c)`.
