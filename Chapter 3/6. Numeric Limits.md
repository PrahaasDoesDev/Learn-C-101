# Numeric Limits

C provides macros describing the ranges of integer types and the properties of floating-point types.

## Integer limits

Include `<limits.h>`:

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("int: %d to %d\n", INT_MIN, INT_MAX);
    printf("unsigned int max: %u\n", UINT_MAX);
    printf("char bit width: %d\n", CHAR_BIT);
    return 0;
}
```

Other useful macros include `SHRT_MIN`, `SHRT_MAX`, `LONG_MIN`, `LONG_MAX`, `LLONG_MIN`, `LLONG_MAX`, and `UCHAR_MAX`. Match each value with the proper `printf` conversion specifier.

## Floating-point limits

Include `<float.h>` for macros such as `FLT_MIN`, `FLT_MAX`, `DBL_MIN`, and `DBL_MAX`.

- `FLT_MAX` and `DBL_MAX` are the largest finite positive values.
- `FLT_MIN` and `DBL_MIN` are the smallest positive normalized values, not the most negative values.
- `-FLT_MAX` and `-DBL_MAX` are the most negative finite values for the corresponding types.
- `FLT_EPSILON` and `DBL_EPSILON` describe the gap between `1.0` and the next larger representable value.

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("float range: %e to %e\n", -FLT_MAX, FLT_MAX);
    printf("smallest positive normalized double: %e\n", DBL_MIN);
    return 0;
}
```

The exact limits depend on the implementation. Use these macros instead of hard-coding platform-specific values. For optional infinity and NaN support, see `<math.h>` and the `HUGE_VAL` family of macros.
