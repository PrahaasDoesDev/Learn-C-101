# Fractional Numbers

Floating-point types approximate real numbers. They can represent very large and very small magnitudes, but most decimal fractions cannot be represented exactly.

## The floating-point types

| Type | Typical size | Typical precision |
|---|---:|---:|
| `float` | 4 bytes | about 6-7 decimal digits |
| `double` | 8 bytes | about 15-16 decimal digits |
| `long double` | implementation-dependent | at least as much precision as `double` |

These are common values, not universal size guarantees. Inspect `<float.h>` for the current implementation's properties.

```c
float f = 3.14f;
double d = 3.141592653589793;
long double ld = 3.141592653589793238L;
```

A floating constant without a suffix has type `double`; `f` or `F` makes it `float`; `l` or `L` makes it `long double`.

## Scientific notation

```c
double large = 1.5e6;   // 1.5 x 10^6
double small = 2.5e-3;  // 2.5 x 10^-3
```

## Precision and comparison

Floating-point arithmetic rounds results to representable values. For example, `0.1 + 0.2` may not be exactly `0.3`. Avoid direct equality checks for computed floating-point values; compare the difference against an application-appropriate tolerance.

```c
#include <math.h>

if (fabs(a - b) < 1e-9) {
    /* close enough for this calculation */
}
```

Choose a tolerance based on the scale and error requirements of the calculation; one fixed tolerance is not suitable for every problem.

## Integer and floating-point division

When both operands are integers, division discards the fractional part toward zero. If either operand is floating-point, the calculation is floating-point.

```c
int whole = 5 / 2;            // 2
double fraction = 5.0 / 2;    // 2.5
```

## Printing floating-point values

In a `printf` call, `%f` expects a `double` (a `float` argument is promoted to `double`):

```c
printf("%.2f\n", 3.14159);    // 3.14
printf("%e\n", 12345.0);      // scientific notation
```

Use `%.nf` to print `n` digits after the decimal point. Printing precision does not increase the value's actual precision.

## What should I use?

- Use `double` as the general-purpose floating-point type.
- Use `float` when memory or an API requires it and its precision is sufficient.
- Use `long double` only when its additional precision is useful on your target.
- For currency, consider integer minor units or a decimal arithmetic approach instead of binary floating point.
