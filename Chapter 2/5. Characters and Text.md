# Characters and Text

## Characters

C uses `char` to store a small integer value, commonly used for a character from the execution character set. A character literal uses single quotes:

```c
char letter = 'A';
```

The value of a character such as `'A'` is defined by the implementation's character set. ASCII is common, but C does not require every system to use ASCII. Use character constants instead of hard-coding numeric character codes.

The plain `char` type may be signed or unsigned. `signed char` and `unsigned char` are distinct integer types. Use `<limits.h>` if you need to inspect their ranges.

```c
int digit = '7' - '0';   // works for the basic decimal digit characters
```

## Character arrays and strings

C has no built-in string object. A C string is a sequence of `char` values terminated by a null character `'\0'`.

```c
char greeting[] = "Hello";
/* Stored as: 'H', 'e', 'l', 'l', 'o', '\0' */
```

The array needs space for the terminator. A string literal has type array of `char` in older C terminology but modifying it has undefined behavior; use a pointer to `const char` when referring to a literal:

```c
const char *message = "Hello";
```

Include `<string.h>` for functions such as `strlen` and `strcmp`. These functions expect properly terminated strings. Ensure destination arrays have sufficient space when copying or assembling text.

## Text encodings

ASCII covers basic English letters, digits, and control codes. It does not represent every language. UTF-8 is a widely used encoding for Unicode text, but one visible character may occupy multiple `char` bytes. A `char` is not necessarily a complete Unicode character.

```c
printf("%c\n", 'A');   // print a character
printf("%d\n", 'A');   // print its integer character-set value
```

Use `%c` for a character and `%s` for a valid null-terminated string. Never pass an unterminated character array to `%s`.
