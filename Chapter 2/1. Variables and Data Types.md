# Variables and Data Types

A variable is a named object with a type. The type determines the set of values it can represent, how much storage it uses, and which operations are meaningful.

## Declaring and initializing variables

```c
int count;             // declared, but not initialized
int apples = 5;        // initialized at declaration
int total = apples + 3;
const double rate = 0.05;
```

An uninitialized automatic variable has an indeterminate value. Do not read it before assigning a value. C initializes objects with static storage duration to zero when no explicit initializer is provided, but relying on that rule for local variables is a common bug.

C does not have C++ brace initialization. In C99 and later, braces are used for aggregate initializers such as arrays and structures:

```c
int values[3] = { 1, 2, 3 };
int zeroes[3] = { 0 };      // remaining elements are also zero
```

## Fundamental types

| Type | Typical use | Important note |
|---|---|---|
| `char` | character or small integer | plain `char` may be signed or unsigned |
| `short`, `int`, `long`, `long long` | integers | sizes and ranges are implementation-dependent within standard minimums |
| `float`, `double`, `long double` | approximate real numbers | decimal fractions are often not exact |
| `_Bool` | truth value | use `<stdbool.h>` for `bool` in C99-C17 |
| `void` | no value | used for functions with no return value and generic pointers |

Use `sizeof(type)` or `sizeof object` to find a size in bytes on the current implementation. A byte is `CHAR_BIT` bits; it is not universally required to be exactly 8 bits, though 8-bit bytes are overwhelmingly common.

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("CHAR_BIT = %d\n", CHAR_BIT);
    printf("sizeof(int) = %zu bytes\n", sizeof(int));
    return 0;
}
```

The `%zu` conversion specifier prints `size_t`, the type returned by `sizeof`.

## Integer literals and number systems

Integer literals can be written in decimal, octal, or hexadecimal. C23 adds binary literals; earlier standard C does not.

```c
int decimal = 42;
int octal = 052;       // base 8, value 42
int hexadecimal = 0x2A; // base 16, value 42
/* C23: int binary = 0b101010; */
```

Hexadecimal is convenient because each digit corresponds to four binary bits (`0` through `F`). A prefix such as `0x` changes how the source literal is interpreted; it is not stored with the value.

## How data is represented

Objects are represented using bits in memory. The interpretation depends on the object's type. The exact size, signed representation details, alignment, and byte order can vary by implementation. Use standard limits and `sizeof`; do not assume that an `int` is always 4 bytes or that every machine is little-endian.

Unsigned integer arithmetic is performed modulo one more than the maximum value of the type. Signed integer overflow is undefined behavior in C; it is not guaranteed to wrap around.

Floating-point types typically use an IEEE 754 representation, but the C implementation defines the properties available on the target. Values such as `0.1` commonly have only an approximation in binary.

## Names and scope

An identifier may contain letters, digits, and underscores, but cannot begin with a digit. C identifiers are case-sensitive and cannot be C keywords such as `int`, `while`, or `return`. Avoid names beginning with underscores, especially at file scope, because many are reserved to the implementation.

Choose descriptive names and consistent `snake_case` conventions. A local identifier is visible within its scope; declare it before use.

## Example

```c
#include <stdio.h>

int main(void)
{
    int item_count = 4;
    double unit_price = 1.25;
    double total = item_count * unit_price;

    printf("%d items cost %.2f\n", item_count, total);
    return 0;
}
```

Use `int` for ordinary counts, `double` for general approximate decimal calculations, and fixed-width integer types from `<stdint.h>` when a specific width is required and available.
