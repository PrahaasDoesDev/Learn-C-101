# Booleans

C99 introduced the built-in type `_Bool`, which stores the values `0` or `1`. In C99 through C17, include `<stdbool.h>` to use the more familiar spelling `bool` and the constants `true` and `false`.

```c
#include <stdbool.h>
#include <stdio.h>

int main(void)
{
    bool is_ready = true;
    printf("%d\n", is_ready);  // 1
    return 0;
}
```

In C23, `bool`, `true`, and `false` are language keywords; `<stdbool.h>` remains available for compatibility.

## Truth values in conditions

C has no separate Boolean result type for most operators: a comparison produces an `int` value of `0` or `1`. In a condition, zero means false and any nonzero value means true.

```c
int count = 5;

if (count) {
    puts("count is nonzero");
}
```

Prefer explicit comparisons when they make the intent clearer, such as `count != 0`.

`sizeof(bool)` is implementation-dependent; do not assume a Boolean occupies exactly one byte or use it to store arbitrary integers. Use an integer type if more than two states are required.
