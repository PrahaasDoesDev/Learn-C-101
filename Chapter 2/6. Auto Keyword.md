# The `auto` Keyword in C

C's `auto` does **not** infer a variable's type. In C17 and earlier, `auto` is a storage-class specifier for a block-scope object; it usually has no practical effect because block-scope variables already have automatic storage duration by default.

```c
int main(void)
{
    auto int count = 10;  // same storage duration as: int count = 10;
    return count == 10 ? 0 : 1;
}
```

This differs from C++'s type-deducing `auto`. C23 still does not use `auto` for C++-style type inference.

Write the type explicitly in C:

```c
int count = 10;
double ratio = 0.5;
char initial = 'A';
```

`typeof` is available as an extension in some compilers and has standard support in newer C dialects, but it is not a general replacement for C++'s initializer-based `auto`. For portable beginner C, declare the intended type.
