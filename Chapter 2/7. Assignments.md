# Assignments

Assignment stores a new value in an already-declared modifiable object. The type of the object does not change.

```c
#include <stdio.h>

int main(void)
{
    int value = 123;
    printf("value: %d\n", value);

    value = 55;
    printf("value: %d\n", value);
    return 0;
}
```

The second output is `55`; an assignment replaces the value stored in `value`.

## Assignment is an expression

An assignment expression evaluates to the value assigned, so assignments can be chained:

```c
int a, b, c;
a = b = c = 5;
```

Although valid, separate assignments are often easier to read. Avoid putting assignments inside larger expressions unless the intent is unmistakable.

## Conversions

The right-hand value is converted to the left-hand type. Information can be lost when converting to a narrower type or from floating point to integer:

```c
int whole = 2.9;   // becomes 2; fractional part is discarded
```

Use explicit casts when a conversion is intentional and check that the value is in range when necessary. The assignment operator is `=`, while `==` compares values.
