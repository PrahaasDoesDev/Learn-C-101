# Integer Modifiers

C integer types can be qualified with `signed` or `unsigned`, and integer types can use the size modifiers `short`, `long`, and `long long`.

## Signed and unsigned

Signed integer types represent negative and positive values. Unsigned types represent zero and positive values. For an unsigned type with `n` value bits, the range is `0` to `2^n - 1`. The exact range is available from headers such as `<limits.h>`.

```c
int temperature = -5;
unsigned int item_count = 12;
```

Unsigned arithmetic wraps modulo the type's range. Signed overflow is undefined behavior. Do not use unsigned merely to prevent negative values: mixed signed/unsigned comparisons can produce surprising results.

## Integer type spellings

These are equivalent type spellings:

```c
short int a;
short b;
signed short int c;
unsigned long long d;
```

For each integer type, `signed` is the default unless `unsigned` is specified. The C standard specifies minimum ranges, not one universal size for all platforms.

| Type | Typical size | Typical use |
|---|---:|---|
| `short` | 2 bytes | smaller integer range |
| `int` | 4 bytes | general-purpose integer |
| `long` | 4 or 8 bytes | wider integer; size varies |
| `long long` | 8 bytes | larger integer range |

These sizes are typical, not guarantees. Check with `sizeof` and `<limits.h>`.

## Fixed-width types

When an exact width matters, `<stdint.h>` provides optional types such as `int32_t` and `uint64_t` when the implementation supports them:

```c
#include <stdint.h>

uint32_t packet_id = 42;
```

Use portable range-aware types where exact widths are not required.

## Check ranges and sizes

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("int: %d to %d (%zu bytes)\n",
           INT_MIN, INT_MAX, sizeof(int));
    printf("unsigned int: 0 to %u (%zu bytes)\n",
           UINT_MAX, sizeof(unsigned int));
    printf("long long: %lld to %lld\n",
           LLONG_MIN, LLONG_MAX);
    return 0;
}
```

Use the matching format specifier when printing each type. Prefer `%zu` for `sizeof` results.

## Which type should I use?

- Use `int` for most ordinary counts and calculations.
- Use `long long` or a `<stdint.h>` type when the required range is larger.
- Use an unsigned type only when wraparound or a nonnegative range is genuinely appropriate.
- Use `size_t` for object sizes and array indexing interfaces that use `size_t`.
